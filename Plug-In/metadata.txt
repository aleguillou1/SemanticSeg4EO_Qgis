about=SemanticSeg4EO provides tools for semantic segmentation of Earth Observation imagery.
    
    Features:
    - Patch extraction from large satellite images (single & batch mode)
    - Deep learning model training (U-Net, DeepLabV3+, SegFormer, HRNet, etc.)
    - Large image prediction with seamless reconstruction
    
    IMPORTANT: This plugin uses an EXTERNAL Python environment for processing.
    PyTorch and other dependencies are NOT installed in QGIS.
    An environment setup wizard guides you through the configuration.
